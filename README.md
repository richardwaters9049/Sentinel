# Sentinel

A defensive threat-hunting and detection-engineering platform for **simulated critical-infrastructure environments**.

Sentinel turns synthetic enterprise and OT telemetry into explainable findings, hunts and investigation timelines. Its analyst console brings together evidence, threat context and behavioural analytics.

Built with Go, PostgreSQL, NATS JetStream, Next.js and Python.

**Status:** Phases 0–7 complete in the simulated lab; Phase 8 security hardening underway, with authenticated console sessions implemented. Behavioural scores support analyst judgement and have documented coverage limitations.

All scenarios use fictional assets and controlled simulations. Sentinel does not target third parties or manipulate real industrial controllers.

See the [docs](docs/README.md) for setup, architecture, development phases and engineering guidance.
